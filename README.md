# Eventos e formação continuada

Gestão de eventos e formação: inscrições, presença, credenciais, certificados e controle de vagas.

Composer: `buriti/i-educar-eventos-formacao-package`

## Para que serve

Permite à SME organizar formação continuada e eventos da rede — da abertura de vagas ao certificado — com grupos, QR/credencial e registro de presença.

## Desenho de funções

| Função | Entrega |
| --- | --- |
| Eventos e turmas de formação | Cadastro, períodos e vagas |
| Inscrições | Inscrição de servidores/participantes |
| Presença | Registro e conferência de presença |
| QR / credencial | Identificação no evento |
| Certificados | Emissão com trilha para assinatura quando aplicável |
| Grupos | Segmentação de público e ofertas |

## Quem usa

- SME / formação
- Servidores participantes
- Organizadores de evento

## Integrações

- Servidor / RH
- Assinatura digital
- Exportação unificada
